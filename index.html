WHY MIRACLE HARNESS

它不是又一块画布，而是项目的全景驾驶舱

长程项目最大的敌人是「失忆」与「失序」。奇迹 Harness 让人类与 Agent 始终共享同一张项目地图，无论换对话、换模型还是换工具。

俯瞰全局

项目目标、施工层级、季节轮回与唯一任务一屏尽览，不再迷失在碎片对话里。

治理文件

以「砖块」组织代码与文档，记录职责、依赖与决策证据，让每个模块都有自己的上下文。

编排提示词

写入收件箱的指令，由 Agent 在任意对话中读取执行；上下文胶囊随时打包交接。

控制进程

四层质量门 + 伊甸园人工验收：果实只有通过验收才被接受，返工、延期与堆肥都有去处。

主动压缩上下文

切对话、换模型、换工具时，自动把关键状态压进胶囊，新 Agent 读完即续上。

SEASONS CYCLE

让项目像四季一样轮回

每轮施工都走完播种、生长、收获、维护四个季节，节奏清晰，结果可验。

S1

春季 · 播种

人类冻结本轮目标、道路、施工层级、唯一任务和验收条件。

S2

夏季 · 生长

Agent 沿已批准道路直接施工、验证并接入当前项目。

S3

秋季 · 收获

候选果实进入伊甸园，通过质量门后由人类决定接受、返工、延期或堆肥。

S4

冬季 · 维护

总结信息、更新接力胶囊、清理技术债务，决定下一轮是否分裂砖块或换壳。

LOCAL-FIRST BY DESIGN

项目记忆留在本机，外部模型只接收你发出的上下文

  • Mission、蓝图、会话索引与界面状态保存在你的 Windows 设备。
  • 模型 API Key 使用系统安全存储，不写入会话数据库与导出记录。
  • 初代仅开放文本对话，不自动移动、覆盖、删除或 Git 提交项目文件。
  • 蓝图 B0 必须由人类批准，未获批准的道路不会伪装成已施工。
  • 项目文件、运行证据与 Git 历史始终是最终事实来源。

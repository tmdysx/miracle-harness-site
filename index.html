BOUNDARIES BEFORE FEATURES

先把边界刻清楚，模块才能自由组装

Agent 会议 ≠ 天使议会 ≠ 众神武库

会议是工作面，议会管理 Agent 身份与委派，武库管理工具和接口。

智慧之泉 ≠ 众神武库

智慧之泉消化外部知识，众神武库登记可执行能力。

项目金字塔 ≠ 项目根系

金字塔表达语义层级，根系吸收仓库、Git、文件与依赖事实。

戒律石板 ≠ 伊甸园

戒律在行动前约束，伊甸园在行动后依据证据验收成果。

SEASONS CYCLE

让项目像四季一样轮回

四季不是界面主题，而是蓝图、戒律、果实和上下文压缩共同驱动的生命周期。

S1

春季 · 播种

人类冻结本轮目标、道路、施工层级、唯一任务和验收条件。

S2

夏季 · 生长

Agent 沿已批准道路直接施工、验证并接入当前项目。

S3

秋季 · 收获

候选果实进入伊甸园，通过质量门后由人类决定接受、返工、延期或堆肥。

S4

冬季 · 代谢

压缩上下文、清理技术债务，并让蓝图与戒律适应下一纪元。

LOCAL-FIRST BY DESIGN

项目记忆留在本机，外部模型只接收你发出的上下文

  • Mission、蓝图、会话索引与界面状态保存在你的 Windows 设备。
  • 模型 API Key 使用系统安全存储，不写入会话数据库与导出记录。
  • 初代仅开放文本对话，不自动移动、覆盖、删除或 Git 提交项目文件。
  • 蓝图 B0 必须由人类批准，未获批准的道路不会伪装成已施工。
  • 项目文件、运行证据与 Git 历史始终是最终事实来源。
